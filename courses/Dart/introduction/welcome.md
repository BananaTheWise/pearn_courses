# Welcome to Dart

Dart is a client-optimized programming language for fast apps on any platform.

## Why Dart?

- **Fast**: Compiles to native code
- **Productive**: Hot reload, great tooling
- **Portable**: Mobile, web, desktop, server

## What You'll Learn

1. Dart syntax and fundamentals
2. Object-oriented programming
3. Asynchronous programming

> **Tip**: Dart is the language behind Flutter!
