# Setting Up Your Environment

## Install Dart SDK

### Windows/macOS/Linux
1. Download from [dart.dev/get-dart](https://dart.dev/get-dart)
2. Run the installer
3. Verify: `dart --version`

### VS Code Extension
Install the **Dart** extension for syntax highlighting and IntelliSense.

dart run hello_world.dart
